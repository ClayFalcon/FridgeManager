## 詳しい説明（4000文字以内）

```
「あれ、まだ卵あったっけ?」「この野菜、いつまでだっけ?」
そんな毎日の"冷蔵庫のもやもや"を、かんたんに解決するアプリです。

うちの冷蔵庫は、"きっちり管理"が続かない人のための冷蔵庫アプリ。
バーコードを1つずつ読み取ったり、数量を細かく入力したりする必要はありません。
食材の「ある・ない」をタップするだけ。だから面倒にならず、毎日続きます。

定番の食材は最初から並んでいるので、ゼロから登録する手間もなし。
今ある食材をタップしていくだけで、ムダ買いやうっかり期限切れを防げます。


■ タップするだけ。在庫更新がとにかくラク
一度追加した食材は、タップひとつで在庫状況を切り替え。
「ある / ない」の2段階でサッと、または「買ったばかり / ちょっとある / 全くない」の
3段階でしっかり。あなたのペースに合わせて選べます。
面倒じゃないから、家族みんなが更新してくれて、共有が形だけにならない。

■ 保管場所ごとに、今ある食材がひと目でわかる
冷蔵庫・野菜室・冷凍庫・パントリーのタブで整理。
「何がどれくらいあるか」を家族みんなで把握できます。
在庫は「ある / ない」の2段階、または「買ったばかり / ちょっとある / 全くない」の
3段階から、使いやすい方を選べます。

■ 賞味期限をわかりやすく管理
カレンダーから期限を入力。期限が近い食材・切れた食材にはバッジが付いて注意を促します。
「賞味期限が近い順」に並べ替えれば、早く使いたい食材がすぐわかります。
食材ごとに"日持ちの目安日数"を設定しておけば、買ってきたときの期限入力もラクラク。

■ 今ある食材で「作れるレシピ」がわかる
レシピを登録しておくと、冷蔵庫の在庫と自動で照らし合わせ。
「作れる」「あと〇品足りない」がひと目でわかります。
足りない材料は、ワンタップで買い物リストへ。

■ 買い物リストで買い忘れゼロ
レシピの不足食材や、思いついた品をリストに追加。
買ってきたらチェック → そのまま在庫にも反映できます。

■ 家族と冷蔵庫をまるごと共有
Googleアカウントで連携すれば、同じ冷蔵庫の中身を家族で共有。
だれかが買い物すれば、みんなの画面にも反映されます。
「これ買ってきて」「もう買ったよ」のすれ違いを防ぎます。

■ アカウントなしでも、すぐ使える
共有を使わないなら、登録不要ですぐスタート。データは端末内に保存されます。


毎日の献立と買い物を、ちょっとラクに。
「うちの冷蔵庫」を、あなたのキッチンのお供にどうぞ。
```

## スクリーンショットの見出し案（1枚目で差別化を主役に）

スクショ上部にキャッチコピーを載せる場合の案。1枚目で「手軽さ」を伝えるのが最重要。

1. **タップで"ある・ない"。それだけ。** （在庫ステータスをタップする画面）
2. バーコードも入力もいらない （定番食材が並んだ一覧画面）
3. 今ある食材で「作れる」がわかる （レシピの作れる/不足バッジ画面）
4. 足りないものは、そのまま買い物リストへ （買い物リスト画面）
5. 家族みんなで、同じ冷蔵庫を共有 （共有画面）
